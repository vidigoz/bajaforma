# Bajaforma — Configurador de Llaveros 3D

El sitio es solo la herramienta para crear llaveros personalizados: al entrar
al dominio se abre directo el configurador (`public/index.html`).

Es un sitio estático, sin paso de build. Netlify publica la carpeta `public/`
tal cual, y cualquier URL vieja redirige a la herramienta (ver `netlify.toml`).
